## Post 3 - Hindi word order (save-worthy)

**Image:** post3.jpg

If you speak Hindi, Japanese grammar will feel familiar 🤯🇮🇳🇯🇵

English: I eat rice (subject → verb → object)
हिन्दी: मैं चावल खाता हूँ (subject → object → verb)
日本語: 私はご飯を食べます (subject → object → verb)

Same order as Hindi! And Japanese uses little words after nouns - just like Hindi:
は (wa) ≈ ने / तो
を (o) ≈ को
で (de) ≈ में / से

That’s why Nihongo Path explains every lesson in English AND हिन्दी. 📚
